# AzyqTulik

PHP негізіндегі азық-түлік дүкені және бөлек әкімші панелі.

## Іске қосу

Жобаның түбірінде екі терминал ашыңыз:

```sh
php -S localhost:8000
```

```sh
php -S localhost:8001 -t Admin
```

- Дүкен: <http://localhost:8000>
- Әкімші панелі: <http://localhost:8001>
- Кіру беті: <http://localhost:8001/login.php>

Әдепкі әзірлеу құпиясөзі — `admin123`. Орта айнымалысы `STORE_ADMIN_PASSWORD` арқылы ауыстыруға болады. Жария ортада әдепкі құпиясөзді қолданбаңыз.

Тапсырыстар мен клиент деректері бар `includes/orders.json.php` Git-ке қосылмайды.
