# Әкімші панелін жергілікті іске қосу

Екі PHP серверді екі терминалда іске қосыңыз:

```sh
php -S localhost:8000
```

```sh
php -S localhost:8001 -t Admin
```

Дүкен: <http://localhost:8000>

Әкімші панелі: <http://localhost:8001>

Кіру беті: <http://localhost:8001/login.php>. Панельге кіру расталмаса, `index.php` осы бетке автоматты түрде бағыттайды.

Әдепкі API мекенжайы — `http://localhost:8000/admin-api.php`. Басқа origin қолданылса, негізгі серверге `ADMIN_APP_ORIGIN` (панельдің origin-і), ал навигация сілтемесін ауыстыру үшін `ADMIN_APP_URL` орнатыңыз. Әкімші құпиясөзін `STORE_ADMIN_PASSWORD` арқылы беріңіз; жария ортаға шығарғанда әдепкі құпиясөзді міндетті түрде өзгертіңіз.

API сессия cookie-сін `credentials: include` арқылы пайдаланады және `ADMIN_APP_ORIGIN` мәніне CORS рұқсатын береді. Негізгі сайт пен панель бірдей `localhost` хостында болғандықтан, порттары бөлек болса да, браузер сессияны жібереді.
